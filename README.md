# Italia 2026 en familia

Guía de viaje estática (HTML + CSS + JS, sin dependencias) para GitHub Pages. Funciona sin internet como PWA.

## Cómo editar
- Todo el contenido está en `data.json`: itinerario (`days`), hoteles, restaurantes (`food`), lugares (`sights`), consejos, emergencias y lista de chequeo.
- Después de editar, sube el número de `VERSION` en `sw.js` (por ejemplo `italia2026-v2`) para que los celulares descarguen la versión nueva.
- Para ver cómo se verá otro día: agrega `?fecha=2026-10-18&hora=12:30` a la URL.

El repositorio es público: no subir códigos de reserva, números de tiquete, pasaportes, correos ni teléfonos personales.
